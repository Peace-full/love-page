### What was changed

The original LoveTree code (written with the Jscex async framework and
jQuery) was rewritten into modern vanilla JavaScript: async/await replaces
Jscex, `Path2D` replaces manual point lists, and the branch layout, colors
and animations were reworked. The core algorithm (heart-shaped tree, bezier
branches, seed → grow → bloom → falling petals) is derived from the
original work.
